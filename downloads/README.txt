Drop your release files here, then set the filenames in config.js:

  android: "downloads/tidetic-android.apk"
  windows: "downloads/tidetic-windows.exe"

Recommended names:
  tidetic-android.apk   — Android APK
  tidetic-windows.exe   — Windows installer (or .zip)

After adding files, redeploy to Vercel (or refresh if serving locally).
